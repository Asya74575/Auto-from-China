# Авто из Китая под ключ — 3D-лендинг

Концепт сайта для портфолио: условная компания «Восток Драйв» (Минск) привозит новые автомобили из Китая под ключ. Компания, цены, отзывы и контакты придуманы, форма заявки ничего не отправляет.

**Что на странице**

- настоящая 3D-машина в «ночном шоуруме»: прелоадер и монтаж крупных планов на первом экране, облёт камерой при прокрутке, смена цвета кузова волной, фары с «зажиганием» и свечением;
- выбор из шести моделей — машина в зале меняется (выезжает старая, заезжает новая);
- калькулятор «под ключ» по строкам: цена в Китае, доставка, пошлина по ставкам РБ, сборы, услуга;
- путь машины по документам и по дням, оплата в три этапа, лента «Что не привезём», отзывы, вопросы, заявка.

**Как открыть**

Сайт статический, без сборки: откройте `index.html` двойным кликом или любым локальным сервером. Подходит для GitHub Pages (публикация из корня ветки `main`).

**Технологии**

HTML, CSS, JavaScript без фреймворков; 3D — [three.js](https://threejs.org/) (MIT), плавная прокрутка — [Lenis](https://github.com/darkroomengineering/lenis) (MIT). Шрифты Science Gothic и Golos Text (SIL OFL), файлы лицензий — в `assets/fonts/`.
